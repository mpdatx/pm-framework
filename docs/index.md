# Overview

pm-framework defines **project-docs**: a convention that keeps a project's architecture
docs, product docs and work status current, a vendored tool (`pmdocs.py`) that enforces it
through git and Claude Code hooks, and a Claude Code skill that sets projects up, migrates
existing ones and triages ad-hoc work into a backlog. It was distilled from four
agent-built projects that had each grown part of this independently.

## About these docs

This repository follows its own convention. Markdown in `docs/` is the source;
`docs/site/` and `docs/roadmap.md` are generated by `uv run scripts/pmdocs.py build` (the
pre-commit hook does it) and are never edited by hand. Ad-hoc ideas go in `TODO.md`.
